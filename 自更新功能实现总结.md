```cpp
bool AppManagerService::upgradeAppManager(const OnlineAppInfo &online,
                                          QString &resultMessage,
                                          int timeoutMs,
                                          const DownloadProgressCallback &progressCallback,
                                          const StatusCallback &statusCallback)
{
    // ... (验证 URL)
    
    // 下载安装程序到临时目录
    if (!downloadToFile(online.downloadUrl, installerPath, resultMessage, 
                        timeoutMs, progressCallback, statusCallback)) {
        return false;
    }
    
    // 启动安装程序
    QStringList arguments;
    arguments << QStringLiteral("/SILENT");      // 静默安装
    arguments << QStringLiteral("/NORESTART");   // 不自动重启
    
    QProcess process;
    if (!process.startDetached(installerPath, arguments)) {
        resultMessage = QStringLiteral("启动安装程序失败");
        return false;
    }
    
    resultMessage = QStringLiteral("安装程序已启动，AppManager 将在完成安装后自动重启");
    return true;
}
```

**功能**:
- 下载安装程序（支持进度回调）
- 启动 Inno Setup 安装程序
- 返回安装程序启动状态

#### 方法: onCheckAppManagerUpdate() (第 1265-1343 行)

```cpp
void MainWindow::onCheckAppManagerUpdate()
{
    appendLog(QStringLiteral("正在检查 AppManager 新版本..."));
    
    // 显示进度对话框
    QProgressDialog checkProgress(...);
    checkProgress.show();
    
    // 从服务器查询
    OnlineAppInfo online = m_service.checkAppManagerUpdate();
    checkProgress.close();
    
    // 错误处理
    if (!online.requestSuccess) {
        logToFile(QStringLiteral("[AppManager] 检查更新失败: %1").arg(online.errorMessage));
        QMessageBox::information(this, QStringLiteral("版本检查"), ...);
        return;
    }
    
    // 版本比较
    const QString currentVersion = m_service.appManagerVersion();
    const QString latestVersion = online.latestVersion;
    
    if (compareVersions(currentVersion, latestVersion) >= 0) {
        QMessageBox::information(this, QStringLiteral("版本检查"),
                                QStringLiteral("AppManager 已是最新版本 (v%1)").arg(currentVersion));
        return;
    }
    
    // 弹出升级确认对话框
    QMessageBox::StandardButton ret = QMessageBox::question(
        this,
        QStringLiteral("发现新版本"),
        QStringLiteral("发现 AppManager 新版本 v%1\n\n当前版本: v%2\n\n是否立即升级?")
            .arg(latestVersion, currentVersion),
        QMessageBox::Yes | QMessageBox::No);
    
    if (ret == QMessageBox::Yes) {
        // ... 执行升级逻辑
        
        // 显示下载进度
        QProgressDialog dlProgress(...);
        
        // 调用升级方法
        QString result;
        if (!m_service.upgradeAppManager(online, result, 30000, 
                                         progressCallback, statusCallback)) {
            // 失败处理
        } else {
            // 成功 - 2秒后关闭应用
            QTimer::singleShot(2000, this, [this]() {
                QApplication::quit();
            });
        }
    }
}
```

**功能流程**:
1. 显示"检查版本"进度对话框
2. 调用 `checkAppManagerUpdate()` 查询服务器
3. 版本比较，决定是否显示升级提示
4. 用户确认后，显示"下载"进度对话框
5. 调用 `upgradeAppManager()` 下载并启动安装程序
6. 2秒延迟后关闭应用（让安装程序接管）

## 🐛 已知限制

1. **版本号来源**：依赖 Windows exe 版本资源
   - 需要在编译时设置版本号
   - 某些场景可能读取失败（返回默认 "1.0.0"）

2. **安装程序启动**：使用 Inno Setup 安装程序
   - 需要服务器提供对应版本的 exe 文件
   - Windows 用户账户权限可能影响安装

3. **自动重启**：应用退出后由安装程序管理重启
   - 无法保证重启完成时间
   - 用户可能需要手动启动应用

4. **回滚机制**：未实现升级失败回滚
   - 建议在安装程序中实现备份机制
   - Inno Setup 本身有"撤销"功能，但需要用户手动操作

## 🔄 后续改进方向

1. **增量更新**：使用 Delta 算法减少下载大小
